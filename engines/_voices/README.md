# 공용 기본 목소리(가상 인물 12명)

복제만 되는 엔진은 참조 클립이 있어야 말할 수 있어요. 이 폴더의 클립이 그 기본 목소리예요.

- **만든 방법**: Qwen3-TTS 1.7B VoiceDesign(가중치 Apache-2.0)에 한국어 인물 묘사를 넣어 만든 소리예요(2026-11-16). 실존 인물의 목소리가 아니고, 누구의 녹음도 쓰지 않았어요.
- **읽은 글**: "안녕하세요. 오늘은 제 목소리로 짧은 이야기를 하나 들려드릴게요. 천천히, 편안하게 들어 주세요." (`voices.yaml` 의 `text`)
- **성별 표시**: 묘사가 아니라 실제 소리의 평균 음높이로 정했어요. 한국어 묘사로는 남성 지정이 잘 안 돼서, 남성 음역은 우진 한 명뿐이에요.
- **라이선스**: 이 클립들은 이 저장소의 라이선스(Apache-2.0)를 따라요. 클립으로 만든 소리를 공개할 때는 AI 로 만든 소리라고 밝혀 주세요.
