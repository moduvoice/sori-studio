- Supertonic-3 가중치: 공식 보관 저장소 `supertone-oss-archive/supertonic-3`(aafc6e3) 먼저, 옛 `Supertone/supertonic-3`(724fb5a, pip 판이 고정한 것) 다음. 두 곳 파일 해시가 같음을 확인했어요.

## 2단계 기록(2026-11-17)
- 화면 `ui/`(React + Vite, `npm run build` → `ui/dist`, 허브가 같은 주소로 내줌): 마법사 6단계(점검 → 모델 폴더 → 쓰임새·추천 → 계획·라이선스 동의·받기 → 자가 시험 듣기 → 시작), 모델 카탈로그(이 PC 판정·거르기·다음 판 엔진·빈자리), 모델 상세 + 설치 패널(계획·용도 제한 원문 끝까지 읽기·진행·멈춤·이어받기·실패 분류·자가 시험), 설치됨(실행 상태·메모리·최근 일·로그·지우기, 디스크), 빠른 시험(듣기·파일 저장·API 예시), 설정(화면·글자 크기·모델 폴더·로컬 API·네트워크·정보), Ctrl+K, 상태 줄, 다크 모드.
- 껍데기 `shell/`(Electron 45): 시작 화면 4단계, 이미 켜진 허브에 붙기, 허브가 죽으면 다시 켜기(10분에 3번), 넘으면 복구 모드(로그·환경 고치기·다시 켜기). 토큰은 허브 주소 화면에만 넘기고, 바깥 링크는 기본 브라우저로.
- 허브 추가: 설정·드라이브·추천(MVP 대응표)·라이선스 원문·로그(경로 가림)·엔진 최근 일·프로세스 묶음 메모리, **API 토큰 따로**(로컬 API 를 켤 때만, /v1 만 - 설치·지우기는 API 로 안 열림), 화면 파일, 받기 중 네트워크 끊김 자동 이어받기(2·5·15초).
- 확인: 허브 시험 24개, `etc/ui_flow.py` 로 새 홈에서 마법사를 실제로 눌러 설치(32초)·빠른 시험까지 콘솔 오류 0, `etc/shell_check.py` 로 허브 강제 종료 → 3초 안에 다시 켬, 4번째에 복구 모드.
- 찾아 고친 것: 받다 잠깐 끊기면 멈춤 → 자동 이어받기, venv 실행기 때문에 메모리 4 MB 로 보임 → 프로세스 묶음 합, Supertonic-3 RTF 를 0.15 로 잘못 적음 → 벤치 0.49, 라이선스 요약에 "AI 생성 밝히기·동의 없는 흉내 금지" 빠짐 → 넣음.

## 공개 전 UX 정리·다국어(2026-11-17, Fable 5.2 리뷰 반영)
- 마법사 6단계 → 3단계(고르기 → 받기 → 들어 보기). PC 점검은 뒤에서, 설치할 곳은 받기 화면의 [바꾸기]로만. 마법사 추천에서는 추가 설치(WSL2)가 필요한 모델을 빼요(목록에는 "추가 설치 필요" 배지로 그대로).
- "빠른 시험" → **"소리 만들기"**(내비 맨 위, 받은 모델이 있으면 첫 화면). 속도는 느리게·보통·빠르게, Qwen3 외국어 억양 목소리는 "다른 억양"으로 접음, API 예시 카드 뺌.
- 뺀 것: "내 목소리" 쓰임새(복제 화면이 없음)와 복제 약속 문구, 빠른 이동(Ctrl+K)·단축키 표시, 상태 줄의 평소 정보(받는 중·문제 있을 때만), 설치됨의 켜기/끄기·메모리·최근 일·디스크 탭(→ "내 모델": 이름·용량·소리 만들기·지우기), 카탈로그의 CPU 만·PC 칩·측정 줄·"다음 판" 자리, 모델 상세의 장치 세 줄·고정한 판·레시피 판.
- 사용 조건 동의 칸은 늘 켜 둠(원문 펼치기 강제 없음), 요약 2줄 + 자세히. 설치 단계는 준비하기·모델 받기·확인하기 셋, 취소는 단추 하나(받은 것은 남김).
- 화면 오류는 허브가 준 kind 로 언어 표에서 골라요(허브 문장은 로그용).
- 다국어: 언어 표 ko·en(키 같음, 복수형 `{one, other}`), 설정 > 일반 > 언어(시스템·한국어·English), 날짜·숫자는 화면 언어 표기, 레시피 문구 `engines/<id>/i18n.yaml`, 공용 목소리 `name_en`, 껍데기 시작·복구 화면 두 언어, 허브→껍데기 신호는 문구 대신 코드(`SORI_NO_PORT`·`SORI_ALREADY_RUNNING`).

## 3단계 기록(2026-11-17)
- 엔진 8개: Windows 에서 바로 - Supertonic-3·Kitten TTS 2 mini(CPU), Qwen3-TTS·VoxCPM2(GPU, torch 2.14.1+cu130 / CPU 판). 리눅스 전용(Windows 는 WSL2) - Confucius4·CosyVoice3·dots.tts·ZONOS3-Mini(GPU, SGLang-Omni 공용 런타임 커밋 고정·해시 잠금).
