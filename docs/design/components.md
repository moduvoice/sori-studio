# Sori Studio 컴포넌트 목록 (v0.1, 2026-11-17)

> 구현할 때 그대로 쓰는 부품 규칙이에요. 토큰 이름(`accent`, `ink-500`, `radius-card` …)은 [`design.md`](design.md) 2절, 배지에 쓰는 말은 8절, 문구 규칙은 10절이 정본이에요.
> 이름은 구현 때 컴포넌트 이름으로 그대로 써도 되게 영어로 붙였어요. 화면 글은 모두 한국어예요.

## 0. 공통 규칙
- **상태 순서**(모든 누르는 부품): 기본 → 올림(hover) → 누름(active) → 포커스(키보드, `focus-ring`) → 바쁨(loading) → 꺼짐(disabled).
- **꺼짐**은 불투명도 45% + 커서 기본. 꺼진 이유가 있으면 말풍선으로 꼭 알려요("이 엔진은 연기 지시를 받지 않아요"). 이유 없는 꺼짐을 만들지 않아요.
- **바쁨**일 때 너비가 바뀌지 않아요(글자 자리에 고리, 또는 글자 앞에 고리).
- 색만으로 상태를 전하지 않아요. 점·배지에는 글자, 아이콘 단추에는 `aria-label` + 말풍선.
- 크기: `sm` 28px · `md` 32px(기본) · `lg` 40px(마법사·빈 화면의 주 단추).
- 한 화면(모달 포함)에 **주 단추는 하나**예요.
- 숫자는 `tabular-nums`. 용량은 GB 소수 한 자리(1 GB 아래는 MB), 시간은 "3.2초"·"약 8분", 비율은 "0.9%".

## 1. Button · IconButton
| 종류 | 모양 | 쓰는 곳 |
|---|---|---|
| `primary` | `action` 바탕 + `on-action` 글자 | 화면의 주 행동 하나(전체 생성 · 받기 시작 · 내보내기 · 다음) |
| `secondary` | `surface` 바탕 + `line-strong` 테두리 + `ink-900` 글자 | 그 밖의 행동(받기(카드) · 일시정지 · 불러오기) |
| `ghost` | 바탕 없음 + `ink-700` 글자, 올리면 `sunken` | 덜 중요한 행동(취소 · 줄 추가 · 도구 줄 아이콘) |
| `link` | `accent` 글자, 올리면 밑줄 | 글 속 이동(측정 근거 보기 · 원문 보기 · 로그 보기) |
| `danger` | `surface` 바탕 + `danger` 테두리·글자. 확인 창 안에서만 `danger` 채움 | 지우기 · 깨끗이 다시 설치 |

- 올림: `primary` 는 밝기 +8%, `secondary` 는 바탕 `sunken`. 누름: 한 단계 더.
- 바쁨: 글자 앞 고리 + 글자를 진행형으로("받는 중…"). 다시 누를 수 없어요.
- 인터넷을 쓰는 단추는 글자 앞에 지구본 아이콘(14px)을 붙여요(새 엔진 확인 · 지금 확인 · 받기 시작).
- 위험한 단추는 사라지는 것을 글자에 적어요("엔진 지우기 · 9.8 GB").
- `IconButton`: 28×28, 아이콘 16px, 말풍선 필수. 켜고 끄는 것(잠금·고정)은 켜짐일 때 `accent-soft` 바탕 + `accent-strong` 아이콘.
- `SplitButton`(전체 생성 ▾): 왼쪽은 기본 행동, 오른쪽 화살표는 범위 메뉴.

## 2. 입력
| 부품 | 규칙 |
|---|---|
| `TextField` · `TextArea` | 높이 32(여러 줄은 내용에 맞춤), `surface` + `line-strong` 테두리, 포커스 `focus-ring`. 오류: `danger` 테두리 + 아래 한 줄(원인 + 고치는 법). 읽기 전용(주소·토큰): `sunken` 바탕 + `mono` + 복사 단추 |
| `SecretField` | 토큰용. 기본은 가림(점), "보기"는 10초 뒤 다시 가려요. 화면 기록·로그에 값을 남기지 않아요 |
| `Select` · `Combobox` | 엔진·목소리 고르기는 줄마다 **상태 점 + 이름 + 보조 글**(판정·종류). 쓸 수 없는 항목은 꺼진 채로 이유를 보여 줘요 |
| `Switch` | 바로 적용되는 설정에만. 켜짐 = `accent`. 라벨은 왼쪽 글, 오른쪽 스위치 |
| `Checkbox` · `Radio` | 여러 개 고르기 · 하나 고르기. 동의 체크는 라벨 전체가 눌려요 |
| `Segmented` | 2~4개 중 하나(WAV/MP3 · 표본율 · 화면 모드). 고른 칸은 `accent-soft` 바탕 + `accent-strong` 글자 + `accent` 테두리(쪽빛으로 꽉 채우지 않아요) |
| `Slider` | 속도(0.5~2.0, 0.05 단위) · 음량. 값은 옆에 숫자로도 넣을 수 있어요 |
| `FilterChip` | 카탈로그 거르기. 켜짐 = `accent-soft` + 체크 |
| `PathField` | 폴더 고르기. 경로(가운데 줄임) + "바꾸기" + 그 드라이브 빈 공간. serve 모드에서는 글자 입력 + "허브 PC 의 경로예요" |

## 3. Badge · StatusDot
- `Badge`: 높이 20, `radius-pill`, `label` 12~13px. 세 가지 꼴 - **테두리만**(중립 사실: 검증됨 · 상업 사용 가능 · Apache-2.0), **옅은 채움**(상태: 만듦 · 오래됨 · 실패, `*-soft` 바탕 + 진한 글자), **회색 채움**(낮은 강조: 보관됨 · 미검증).
- `StatusDot`: 지름 8px 점 + 글자. 진행 상태는 점 대신 도는 고리(12px).
- 배지 묶음과 값·색은 `design.md` 8절 표 그대로예요. 요약:

| 묶음 | 부품 | 아이콘 |
|---|---|---|
| 이 PC 판정 | `StatusDot` | 점(초록·호박·빨강·회색) |
| 근거 등급 | `Badge` 테두리 | 없음 |
| 라이선스 | `Badge` 테두리(조건부 = 호박 테두리, 비상업 = 빨강 테두리, 미확인 = 회색 채움) | 문서 배지 |
| 유지보수 | `Badge`(보관됨 = 회색 채움) | 보관 상자 |
| 설치 | `Badge` 또는 진행 막대 | 체크 · 고리 |
| 엔진 실행 | `StatusDot` | 점 · 고리 |
| 줄 상태 | `Badge` 옅은 채움 | 체크 · 시계 · 고리 · 세모 · 가위표 |
| 태그 확인 | `Badge` | 귀 |
| 동의 | `Badge` | 체크 · 방패 |

- 모든 배지는 말풍선으로 뜻을 한 줄 풀어 줘요(예: 검증됨 = "우리가 재고 사람이 들어 본 엔진이에요 · 2026-11-16").
- 한 줄에 배지는 4개까지. 넘으면 "+2"로 접어요.

## 4. EngineCard (모델 카탈로그의 카드)
```
┌──────────────────────────────────────────────┐
│ 이름(h2)                        [근거 등급]    │
│ 만든 곳 · 맡을 일(ink-500)                      │
│ ● 판정 · 필요한 메모리                          │
│ "사람 평가 한 줄"(body, ink-900)                │
│ 발음 오류율 0.9% · 환각 5/647(caption, ink-500) │
│ [라이선스] [유지보수]                           │
│ ─────────────────────────────────────────── │
│ 8.2 GB                              [받기]     │
└──────────────────────────────────────────────┘
```
- 최소 너비 360px, 2열(기본) · 3열(넓은 창). 카드 전체가 눌리고(→ 모델 상세), 단추는 따로 눌려요.
- 카드의 "받기"는 `secondary` 예요(주 단추는 모델 상세의 "받기 시작").

| 상태 | 바뀌는 것 |
|---|---|
| 안 받음 | 아래 줄: 받을 양 + "받기" |
| 받는 중 | 아래 줄이 진행 막대 + "패키지 62% · 2분 남음" + 일시정지 아이콘 |
| 멈춤 | "멈춤 · 1.9 / 5.1 GB" + "이어서 받기" |
| 실패 | 카드 테두리 `danger`, "받다가 끊겼어요" + "이어서 받기" |
| 설치됨 | 초록 체크 "설치됨" + "열기" |
| 업데이트 있음 | "설치됨" 옆 쪽빛 점 + "새 레시피가 있어요" |
| 안 돌아요 | 카드 글이 `ink-500` 으로 옅어지고 판정에 이유. 단추는 "자세히" |
| 출처 바뀜·사라짐 | 호박 줄 "공식 출처가 바뀌었어요". 받은 사용자는 "설치됨" 그대로 |
| 불러오는 중 | 뼈대(이름 줄 · 세 줄 · 단추 자리) |

- `EmptySeatRow`(빈자리 줄): 점선 테두리, `ink-500` 글 "사투리 - 아직 오픈소스 후보가 없어요". 눌리지 않아요.

## 5. EngineRow (설치됨 표의 줄) · EngineState
- 칸: 이름 · 상태(`StatusDot`) · 메모리 · 레시피 판(`mono`) · 디스크 · 할 일(단추 1~2개 + 더 보기 메뉴).
- 줄 높이 52px. 고른 줄은 `accent-soft`, 죽은 엔진 줄은 `danger-soft`.

| 실행 상태 | 표시 | 메모리 칸 | 할 일 |
|---|---|---|---|
| 켜짐 | 초록 점 "켜짐" | "GPU 6.6 GB" 또는 "CPU 4스레드" | 내리기 |
| 불러오는 중 | 쪽빛 고리 "불러오는 중 · 약 40초" | "-" | 멈추기 |
| 쉬는 중 | 회색 점 "쉬는 중" (말풍선: "5분 동안 안 써서 메모리에서 내렸어요. 쓰면 다시 올라와요") | "-" | 켜기 |
| 멈춤 | 호박 점 "멈춤 · 답이 없어요" | 마지막 값 | 다시 켜기 |
| 다시 켜는 중 | 호박 고리 "다시 켜는 중 · 2번째 · 10초 뒤" | "-" | 멈추기 |
| 죽음 | 빨강 점 "죽음" | "-" | 고치기 · 다시 설치 |

- 더 보기 메뉴: 빠른 시험 · 로그 보기 · 지우기(통째 / 환경만 / 가중치만) · 모델 상세.
- `EngineStatePill`: 같은 상태를 한 줄로 줄인 것(상태 점 + 엔진 이름). 캐릭터 패널·엔진 고르기·상태 줄에 써요.
- `EventTimeline`(최근 일): 시각(`mono`, `ink-500`) + 점 + 한 줄. 점 색은 오류만 `danger`, 스스로 고친 것은 `ink-400`, 사용자가 한 일은 `accent`. 최근 50개, 위가 옛것.

## 6. InstallPanel (모델 상세 오른쪽, 마법사 4단계)
한 패널이 상태에 따라 내용을 바꿔요. 너비 420px.

| 상태 | 내용 | 주 단추 |
|---|---|---|
| `plan` | `KeyValueList`: 엔진 환경 · 가중치 · 받을 양 · 설치 뒤 디스크 · 예상 시간 · 출처 · 판. 디스크가 모자라면 `Banner`(호박) + 지울 후보 | 받기 |
| `consent` | `LicenseBox` | 받기 시작(체크 전에는 꺼짐) |
| `running` | `StepList`(동의 · 파이썬 환경 · 패키지 · 가중치 · 자가 시험) + `ProgressBar` + "2.1 / 3.4 GB · 12 MB/s · 2분 남음" | 일시정지 (ghost: 취소) |
| `paused` | 같은 목록, 멈춘 단계에 "멈춤" | 이어서 받기 |
| `failed` | 실패한 단계에 가위표 + 분류별 문구(design.md 6.2) + "자세히"(로그) | 분류별(이어서 받기 · 정리하기 …) |
| `selftest` | "한국어 세 문장을 만들어 볼게요" + 문장 3줄(체크) + 듣기 | (끝나면) 다음 |
| `selftest-failed` | "받기는 끝났지만 시험 소리를 만들지 못했어요. 아직 설치된 게 아니에요." | 다시 시험 |
| `installed` | 초록 체크 "설치됨" · 레시피 판 · 디스크 · 자가 시험 시각 | 빠른 시험 (secondary: 이 엔진으로 캐릭터 만들기, ghost: 지우기) |

- `LicenseBox`: 제목 "라이선스 · Apache-2.0", 요약 3~5줄(상업 · 호스팅 · 표시 의무 · 금지 용도), `link` "원문 보기", `caption` "요약은 참고용이고 원문이 우선해요.", 체크 "라이선스를 읽었고 동의해요".
  - **OpenRAIL 계열**: 요약 줄 대신 **용도 제한 조항 원문**을 스크롤 상자(`sunken`, 최대 높이 200px)에 그대로 넣어요. 끝까지 내려야 체크가 켜져요.
  - 게이트 모델: 체크 대신 "공식 페이지 열기" → `SecretField`(토큰).
- `StepList` 한 줄: 아이콘(끝남 = 초록 체크 / 진행 = 쪽빛 고리 / 기다림 = 회색 동그라미 / 실패 = 빨강 가위표 / 건너뜀 = 회색 줄) + 이름 + 오른쪽 값(%·걸린 시간).
- 취소 확인 창: "받은 파일은 남겨 둘까요?" - 남기기(다음에 이어받기) / 지우기.

## 7. ScriptLine (대본 줄)
```
[번호] [캐릭터 칩] 대사(script 15px) ............................ [▶] [상태 배지] [🔒]
        └ 알림 줄(caption): "[웃음]은 이 엔진이 받지 못해 빼고 만들어요."
        └ (고른 줄) [연기 ▾] [속도 1.0] [뒤 쉼 0.3초] [엔진 ▾] [테이크 1·2·3] 엔진에 간 글
        └ (고른 줄) 42자 · 약 3.4초 · 만드는 데 약 6초
        └ (제안이 있으면) ⟡ 제안: 연기 "놀람" [✓][✕]
```
- 줄 사이는 `line` 한 줄, 줄 안쪽 여백 위아래 12px. 고른 줄: 왼쪽 3px `accent` 막대 + `accent-soft` 바탕.
- **캐릭터 칩**: 머리글자 동그라미(24px, `ink-700` 바탕 + 흰 글자) + 이름. 누르면 캐릭터 바꾸기. 색으로 캐릭터를 구분하지 않아요.
- **대사**: 보이는 글 그대로. 공통 표기(`[쉼 0.5초]` · `[웃음]`)는 `sunken` 바탕 조각으로, 읽기 지정한 낱말은 점선 밑줄(올리면 읽기)로 보여요. 엔진이 못 받는 표기 조각은 가운데 줄 + 호박 테두리.

| 줄 상태 | 배지 | 듣기 단추 | 일괄 생성에서 |
|---|---|---|---|
| 안 만듦 | 회색 "안 만듦" | 꺼짐 | 만듦 |
| 기다림 | 회색 시계 "기다림" | 꺼짐(옛 테이크가 있으면 그걸 들려줌) | 차례 기다림 |
| 만드는 중 | 쪽빛 고리 "만드는 중" | 꺼짐 | - |
| 만듦 | 초록 체크 "만듦" | 켜짐 | 건너뜀(지문이 같음) |
| 오래됨 | 호박 "오래됨" | 켜짐(옛 테이크) | 만듦 |
| 의심 | 호박 세모 "의심" + 이유 말풍선 | 켜짐 | 만듦(범위가 "의심 줄만"일 때) - v1 |
| 실패 | 빨강 "실패" + 줄 아래 원인 한 줄 + "다시" | 꺼짐 | "실패한 줄만 다시"에서 만듦 |
| + 잠금 | 배지 옆 자물쇠 | 켜짐 | **늘 건너뜀** |

- 줄 올림: 오른쪽에 더 보기 메뉴(복제 · 위아래로 · 합치기 · 나누기 · 이 줄로 엔진 비교 · 지우기)와 왼쪽에 끌기 손잡이.
- 글 고치는 중: 줄 테두리 `focus-ring`, 글자 단축키 꺼짐. 고치고 나오면 지문을 다시 계산해 "오래됨"으로.
- `LineControls`(줄 설정): 연기(`Select`: 고정 7개 + 자유 글) · 속도 · 뒤 쉼 · 엔진 바꾸기(이 줄만) · `TakeChips` · "엔진에 간 글". 엔진이 못 받는 칸은 꺼짐 + 이유.
- `EngineTextDiff`(엔진에 간 글): 두 줄 - "보이는 글" / "엔진에 간 글". 바뀐 곳은 `accent-soft` 바탕, 뺀 표기는 가운데 줄. 아래에 바꾼 이유 목록(숫자 읽기 · 발음 사전 "갈등 → 갈뜽" · 표기 뺌 · 연기 지시 영어로).
- `InsertMenu`(넣기 메뉴): 쉼(초 입력) · 웃음 · 한숨 · 숨 · 울음 · 헐떡임 · 읽기 지정. 항목마다 그 엔진에서의 상태: 켜짐 / "귀로 확인 필요" / 꺼짐 + 이유.
- `SuggestionChip`(LLM 제안): 점선 `accent` 테두리 + 반짝이 아이콘 + "제안" + 내용 + ✓ / ✕. 적용하면 보통 값으로 바뀌고 칩은 사라져요.

## 8. TakeChip · TakeList (테이크)
- `TakeChip`(줄 안): 22×22 숫자 칩. 기본 = `surface` + `line-strong` / 듣는 중 = `accent` 테두리 + 작은 파형 움직임 / **고정** = `accent` 채움 + 흰 숫자 / 만드는 중 = 고리. 6개까지, 넘으면 "+n".
- `TakeList`(테이크 패널) 한 줄: 듣기 단추 · "테이크 2" · 씨앗(`mono`) · 길이 · 만든 시각 · 고정 표시(압정) · 더 보기(고정 · 파일로 저장 · 지우기 · 이 설정으로 되돌리기).
  - 고정된 테이크 줄: `accent-soft` 바탕 + 압정 + "고정". 고정은 줄마다 하나예요.
  - 판이 다른 테이크(엔진 레시피가 바뀜): `caption` "레시피 1.1.0 으로 만든 테이크예요".
- `VariantButton`: "변형 3개 더"(옆 숫자 조절 2~6). 만드는 동안 새 칩이 고리로 먼저 생겨요.
- `ABCompare`: 테이크 둘을 고르면 파형 두 줄이 위아래로 나란히, 1·2 키로 같은 위치에서 번갈아 들어요.
- `RecipeBlock`(만든 방법): `sunken` 바탕, `mono` - 엔진 · 레시피 판 · 목소리 · 씨앗 · 속도. "복사".

## 9. Waveform · Player
- `Waveform`: 세로 막대(너비 2px, 사이 2px, 끝 둥글게). 듣기 전 = `ink-400`, 지나간 부분 = `accent`, 재생 위치 = 1px `accent` 세로줄. 바탕은 `surface`(큰 것은 `sunken`).
  - 크기: `sm` 높이 24(줄 안·목록) · `md` 48(카드) · `lg` 96(테이크 패널·빠른 시험).
  - 누르면 그 자리부터 재생, 끌면 구간 고르기(참조 클립 자르기에서만).
  - 불러오는 중: 같은 높이의 회색 막대 뼈대. 소리 없음: 가운데 가는 줄 + "아직 만들지 않았어요".
- `PlayButton`: 동그라미 28(줄) · 36(카드) · 44(패널). 멈춤 = 세모 / 재생 중 = 두 줄(`accent` 채움) / 불러오는 중 = 고리 / 꺼짐.
- 한 번에 하나만 재생해요. 다른 것을 누르면 앞의 것은 멈춰요.
- `TrimEditor`(참조 클립 자르기): `lg` 파형 + 양끝 손잡이 + 엔진별 권장 길이 눈금("VoxCPM2 10초", "Qwen3-TTS 10초") + 고른 길이.

## 15. 구현 메모
- 토큰은 CSS 변수로 두고(`--color-accent` …) `data-theme="light|dark"` 로 값만 바꿔요. 부품 안에 색 값을 직접 쓰지 않아요.
- 문구는 모두 문자열 표에서 가져와요(design.md 10.2). 부품 안에 한국어 글을 박아 넣지 않아요.
- 상태 값(설치 · 실행 · 줄)은 허브 API 가 주는 값과 1:1 로 맞춰요. 화면에서 상태를 새로 지어내지 않아요(기능 설계에 없는 상태는 design.md 13절 2번에 적었어요).
- 아이콘은 Lucide 이름으로 정해 둬요: 프로젝트 `folder` · 대본 `file-text` · 목소리 `mic` · 비교 `scale` · 모델 `box` · 설치됨 `download` · 빠른 시험 `zap` · 설정 `settings` · 고정 `pin` · 잠금 `lock` · 라이선스 `file-badge`(비교의 저울과 겹치지 않게) · 보관됨 `archive` · 인터넷 `globe` · 제안 `sparkles`.
