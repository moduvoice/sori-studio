# 화면 리빌딩 계획(2026-11-17) - "product 급"으로

사용자: "디자인이 너무 심심하다, product 급으로" + 참고 화면(VoiceStudio Electron 화면 - 느낌만 참고, 코드는 가져오지 않아요(AGPL)).
지키는 것: 앞 UX 리뷰의 **단순함**(마법사 3단계, "소리 만들기" 중심, 만든 사람 말 숨김), 한국어·영어 언어 표, 허브 API 는 그대로.

## 1. 바꾸는 방향
| 지금 | 바꾼 뒤 |
|---|---|
| 밝은 종이 바탕, 평평한 카드 | **어두운 화면이 기본**(밝은 화면은 설정에서). 거의 검정 바탕 위에 한 단계씩 밝은 패널을 겹치고, 얇은 테두리(흰색 7%)로 나눠요 |
| 글자 메뉴 내비 | **왼쪽 아이콘 막대**(56px, 마우스를 올리면 이름) + 화면마다 필요한 패널 |
| 소리 만들기 = 폼 한 장 | **세 칸 작업 화면**: 왼쪽 목소리 목록(얼굴 대신 이니셜 원 + 성별·모델) · 가운데 대본(큰 글 영역, 글자 수) + 아래에 떠 있는 [만들기] 막대(모델·속도·만들기 Ctrl+Enter) · 오른쪽 만든 소리(큰 파형, 저장, 방금 만든 것 목록) |
| 첫 화면 = 모델 목록 | **홈**: 큰 제목 + 한 줄 소개, 큰 기능 카드 3개(소리 만들기·모델 찾기·내 모델 - 그라데이션 아이콘 + 얇은 선 그림), 받은 모델과 방금 만든 소리 |
| 모델 카드 격자 | **목록 줄**(이름·한 줄 설명·배지·크기·[받기]) - 펼치면 평·사용 조건. 상세 화면은 같은 어두운 패널 |
| 마법사 흰 화면 | 어두운 바탕에 은은한 빛(방사형 그라데이션)과 얇은 곡선, 가운데 유리 같은 카드 |
| 파형 회색 막대 | 재생한 부분은 보라→분홍 그라데이션, 둥근 막대 |

## 2. 토큰(어두운 화면 기본)
- 바탕 `#0A0B0E` · 패널 `#111318` · 올라온 면 `#171A20` · 눌린 면 `#0D0F13` · 선 `rgba(255,255,255,.07)` / 강한 선 `rgba(255,255,255,.14)`
- 글자 `#ECEEF2` / 보조 `#A2A7B1` / 흐림 `#6B7180`
- 강조 보라 `#7C5CFF`(그라데이션 `#7C5CFF → #C084FC`), 주 단추는 보라 채움(어두운 화면) - 밝은 화면은 잉크 검정 단추 그대로
- 상태: 초록 `#34D399` · 노랑 `#FBBF24` · 빨강 `#F87171`(옅은 배경 12%)
- 둥글기 패널 14px · 카드 12px · 단추 10px, 그림자는 어두운 화면에서 거의 안 씀(대신 테두리·빛)
- 글꼴 Pretendard 그대로, 제목은 굵기 700·자간 -0.02em

## 3. 화면별
1. **앱 틀**: 아이콘 막대(로고 · 홈 · 소리 만들기 · 모델 · 내 모델 … 아래 설정), 위 얇은 머리줄(화면 이름 + 오른쪽 GitHub 별 단추 자리 없음 - 광고·바깥 연결 없음). 상태 줄은 받는 중·문제 있을 때만(지금 규칙).
2. **홈**(새 화면, 받은 모델이 있으면 첫 화면): "Sori Studio" + "내 PC 에서 돌리는 무료 한국어 TTS". 기능 카드 3개, 받은 모델 줄(바로 만들기), 방금 만든 소리.
3. **소리 만들기**: 세 칸(1절). 좁은 창(1120px)에서는 오른쪽 칸이 아래로.
4. **모델**: 목록 줄 + 위 거르기(이 PC 에서 도는 것만) + 찾기. 줄을 누르면 상세.
5. **모델 상세**: 왼쪽 정보(평·품질 타일·목소리·어디에 좋나요) / 오른쪽 설치 패널(지금 흐름 그대로, 어두운 패널).
6. **내 모델**: 목록 줄(이름·용량·[소리 만들기]·[지우기]).
7. **설정**: 왼쪽 항목 목록 + 오른쪽 내용(참고 화면의 설정 틀).
8. **마법사**: 3단계 그대로, 어두운 빛 배경 + 가운데 카드. 쓰임새 카드는 그라데이션 아이콘.
9. 시작·복구 화면(`shell/startup.html`)도 같은 어두운 바탕·로고로.
